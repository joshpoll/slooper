Slooper

Slow it down, loop it, count yourself in.

  1. The last song you used opens here by itself. To switch, pick another from the song menu at the top.
  2. Drag the red A and B markers, set a speed, and press Play.
  3. Each song comes with a waveform and beats, so the markers snap to the beat and the count strip counts in eights.

To add a song to the list, run uv run tools/analyze.py with its YouTube link on the laptop, then commit and push. The song shows up here once the site updates.

Loop points and speed are remembered for each video.
